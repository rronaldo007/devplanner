About DevPlanner

DevPlanner is a small Django app for developers who want to think a project through before they start typing. You answer a focused interview about your idea — who it's for, what's in scope, how it makes money, what the stack looks like, what data lives where — and DevPlanner turns the answers into:

  • a Business Plan
  • a Cahier des Charges (specifications document)
  • User Stories for every persona
  • three Mermaid diagrams: use case, entity-relationship, user flow
  • any custom documents you want to add — e.g. a technical architecture, a deployment plan, a README draft

Two engines

Documents are written either by built-in templates (FR or EN, fully deterministic) or by Anthropic Claude when you add your API key in Settings. Diagrams are always produced deterministically from the data so the Mermaid syntax stays valid.

Multi-user

Every account has its own dashboard, its own projects, and its own Claude API key. Nothing leaks between users.
