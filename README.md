# DevPlanner

A small Django app that interviews a developer about a project idea and then
generates:

- a **Business Plan**
- a **Cahier des Charges** (specifications)
- **User Stories**
- **Mermaid diagrams**: use case, ERD, user flow

Documents can be generated by either:

1. **Built-in templates** (no API key needed) — always available, deterministic.
2. **Claude (Anthropic)** — used automatically when `ANTHROPIC_API_KEY` is set
   and the `anthropic` package is installed. Falls back to templates on any
   error.

Output is shown in-browser (rendered Markdown + live Mermaid diagrams) and
each document can be downloaded as `.md`.

## Quick start

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python manage.py migrate
python manage.py runserver
```

Open <http://127.0.0.1:8000/>, click **+ New project** and answer the
interview. The detail page renders the generated documents and diagrams.

### Using Claude (optional)

```bash
export ANTHROPIC_API_KEY=sk-ant-...
# optional: override the model (defaults to claude-opus-4-5)
export ANTHROPIC_MODEL=claude-opus-4-5
python manage.py runserver
```

On the project detail page you can force one engine or the other via
`?engine=templates` / `?engine=claude` query params.

## Interview structure

The interview is one page with seven sections:

1. **Identity** — name, tagline, output language (FR/EN)
2. **Problem & Solution** — pain point, solution, differentiation, competitors
3. **Audience** — target users + personas (`Name | Role | Goal` per line)
4. **Scope** — must-have features, nice-to-have, out-of-scope (one per line)
5. **Business** — business model, success metrics
6. **Technical** — stack, integrations, hosting, data model entities
7. **Constraints & Risks** — timeline, budget, risks

Data model entities use a tiny indented DSL:

```
User
  email
  name

Task
  title
  user        <- field name matching another entity becomes a relationship in the ERD
  status
```

## Project layout

```
devplanner/        Django project settings + urls
planner/           the planner app
  forms.py         InterviewForm
  models.py        Project model
  views.py         home / new / edit / detail / download / delete
  urls.py
  admin.py
  templatetags/    custom template filters (getfield, dict_get)
  generators/
    __init__.py    generate(project) entrypoint, engine selection
    templates.py   built-in Markdown generator (FR + EN)
    claude.py      Anthropic Claude generator
    diagrams.py    Mermaid use-case, ERD, flow
  templates/planner/
    base.html
    home.html
    interview.html
    project_detail.html
  static/planner/style.css
```

## Tests

```bash
python manage.py test planner
```

The suite covers the form parsers, both generators (with the Claude SDK
stubbed via `unittest.mock`), the diagram producers and the views.
